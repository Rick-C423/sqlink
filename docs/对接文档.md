## 1. 对接架构

```text
React 组件
  └─ Zustand stores
       └─ src/services/tauriService.ts
            └─ invoke("command_name", camelCase 参数)
                 └─ src-tauri/src/commands/*.rs
                      └─ ConnectionPoolManager
                           └─ DatabaseDriver trait
                                ├─ MySQL/MariaDB
                                ├─ PostgreSQL
                                ├─ SQLite
                                └─ SQL Server
```

对接代码的权威来源：

- 前端方法和参数：`src/services/tauriService.ts`。
- 前端类型：`src/types/database.ts`。
- 后端注册列表：`src-tauri/src/lib.rs`。
- 后端命令签名：`src-tauri/src/commands/`。
- 后端序列化模型：`src-tauri/src/models/mod.rs`。
- 驱动契约：`src-tauri/src/database/mod.rs`。

## 2. 通用约定

### 2.1 调用方式

```ts
import { invoke } from "@tauri-apps/api/core";

const result = await invoke<QueryResult>("query_execute", {
  connectionId,
  sql,
  database,
  queryId,
  record: true,
});
```

业务组件不应直接新增散落的 `invoke()`。先在 `tauriService.ts` 增加带类型的方法，再由组件调用。

### 2.2 命名和序列化

- Rust 字段使用 snake_case。
- 共享模型通过 `serde(rename_all = "camelCase")` 输出给前端。
- Tauri command 的前端参数也使用 camelCase，例如 Rust `connection_id` 对应 `connectionId`。
- 命令名保持 snake_case，例如 `schema_get_tables`。
- 前后端新增字段时必须同时修改 Rust model 与 TypeScript interface。

### 2.3 成功和错误

- 后端命令通常返回 `Result<T, String>`。
- 成功值由 Tauri 序列化为 JSON。
- 失败值目前是用户可读字符串，前端通过 Promise reject 接收。
- 当前没有稳定的结构化错误码，不要依赖中文错误文本做核心业务分支。

### 2.4 数据值

- 查询结果列定义在 `QueryResult.columns`，行值在 `rows[n].values`，按索引一一对应。
- 数据库 NULL 与空字符串必须区分。
- JSON 数字受 JavaScript 安全整数范围限制，大整数需要跨驱动验证。
- 日期、时间、Decimal、二进制和驱动特殊类型最终如何显示，以各驱动的 JSON 转换实现为准。

## 3. 核心数据模型

### 3.1 ConnectionConfig

```ts
interface ConnectionConfig {
  id?: string;
  name: string;
  driverType: "mysql" | "mariadb" | "postgres" | "postgresql" |
              "sqlite" | "sqlserver" | "mssql" | string;
  host: string;
  port: number;
  user: string;
  password: string;
  database: string;
  encrypt?: boolean;
  savePassword?: boolean;
  groupName?: string;
  color?: string;
}
```

- `id` 为空时，后端保存连接会生成 UUID。
- `encrypt` 当前主要控制 SQL Server TLS，旧配置缺省按 `false` 处理。
- `savePassword === false` 时密码不落盘。
- 连接列表返回时 `password` 始终为空，不能从列表接口取回明文或密文。
- 更新连接时 `password` 为空表示保留原密码。
- `groupName` 只做了模型预留，当前没有完整分组 UI。
- SQLite 的文件路径使用 `database` 字段。

### 3.2 QueryResult

```ts
interface QueryResult {
  columns: ColumnMetadata[];
  rows: RowData[];
  totalCount?: number;
  executionTimeMs: number;
  rowsAffected?: number;
  lastInsertId?: number;
  truncated: boolean;
}
```

`ColumnMetadata` 包含 `name`、`dataType`、`unifiedType`、`nullable`、`length?`、`precision?`、`scale?`。

注意：当前 Rust `QueryResult` 有 `lastInsertId`，而 TypeScript `QueryResult` 尚未声明该字段；如果前端要使用插入 ID，应先修复类型差异。

### 3.3 Schema 模型

| 模型 | 关键字段 |
| --- | --- |
| `DatabaseInfo` | `name`、`accessible` |
| `TableInfo` | `name`、`schema?`、`rowCount?`、`engine?`、`comment?` |
| `ColumnInfo` | `name`、`dataType`、`nullable`、`isPrimaryKey`、`defaultValue?`、`extra?`、`comment?` |
| `IndexInfo` | `name`、`columns[]`、`isUnique`、`isPrimary` |
| `ForeignKeyInfo` | `name`、`columns[]`、`refTable`、`refSchema?`、`refColumns[]`、`onUpdate?`、`onDelete?` |
| `DbUserInfo` | `name`、`host?`、`note?` |
| `CurrentUserInfo` | `user`、`grants[]` |

`DatabaseInfo.accessible` 用于展示当前账号是否能访问数据库；只需名称时调用 `schema_get_databases`，需要访问状态时调用 `schema_get_database_infos`。

### 3.4 其他模型

| 模型 | 字段 |
| --- | --- |
| `ImportSummary` | `statements`、`executed`、`skipped` |
| `DumpSummary` | `tables`、`rows` |
| `HistoryEntry` | `id`、`connectionId`、`database?`、`sql`、`executedAt`、`durationMs`、`rowCount?`、`truncated` |
| `EditContext` | `connectionId`、`database`、`schema?`、`table`、`primaryKeys[]`、`driverType` |
| `ResolvedTable` | `database`、`schema?`、`table`、`columns[]` |
| `QueryExecution`（前端） | `connectionId`、`database`、`driverType`、`taskId`、`queryId?`、`sql`、`refreshSql?` |

`executedAt` 为 Unix epoch 毫秒。

## 4. IPC 命令清单

当前 `src-tauri/src/lib.rs` 共注册 40 个命令。

### 4.1 连接管理（9 个）

| 命令 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `connection_test` | `config` | `void` | 只测试配置，不保存 |
| `connection_create` | `config` | `string` | 创建内存活动连接，返回连接 ID |
| `connection_disconnect` | `connectionId` | `void` | 断开并移除活动连接 |
| `connection_list` | 无 | `ConnectionConfig[]` | 当前活动连接，密码清空 |
| `connection_save` | `config` | `string` | 加密保存并建立活动连接 |
| `saved_connections_list` | 无 | `ConnectionConfig[]` | 已保存配置，密码清空 |
| `connection_connect_saved` | `id` | `string` | 后端解密保存的密码并连接 |
| `connection_delete_saved` | `id` | `void` | 删除配置并断开活动连接 |
| `connection_update` | `config` | `void` | 更新配置，之后断开活动连接 |

`connection_create` 不等同于保存；需要重启后自动连接的配置必须调用 `connection_save`。

### 4.2 查询与 CSV（4 个）

| 命令 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `query_execute` | `connectionId, sql, database?, queryId?, record?` | `QueryResult` | 自动区分结果集语句和执行语句 |
| `query_cancel` | `connectionId, queryId` | `void` | MySQL/PG/SQLite 支持方式不同；SQL Server 暂不支持 |
| `query_execute_batch` | `connectionId, database?, statements[]` | `number` | 同一事务内批量执行，失败回滚 |
| `table_export_csv` | `connectionId, database?, table, path` | `number` | 整表导出，返回行数 |

`record` 仅用于需要记录到查询历史的手工查询；Schema 和后台查询不应污染历史。

### 4.3 Schema（17 个）

| 命令 | 参数 | 返回 |
| --- | --- | --- |
| `schema_get_databases` | `connectionId` | `string[]` |
| `schema_get_database_infos` | `connectionId` | `DatabaseInfo[]` |
| `schema_get_tables` | `connectionId, database?` | `TableInfo[]` |
| `schema_get_columns` | `connectionId, database?, table` | `ColumnInfo[]` |
| `schema_resolve_table` | `connectionId, database, tableParts[]` | `ResolvedTable` |
| `schema_get_indexes` | `connectionId, database?, table` | `IndexInfo[]` |
| `schema_get_foreign_keys` | `connectionId, database?, table` | `ForeignKeyInfo[]` |
| `schema_get_views` | `connectionId, database?` | `TableInfo[]` |
| `schema_get_view_definition` | `connectionId, database?, view` | `string` |
| `schema_get_triggers` | `connectionId, database?` | `TableInfo[]` |
| `schema_get_trigger_definition` | `connectionId, database?, trigger` | `string` |
| `schema_get_procedures` | `connectionId, database?` | `TableInfo[]` |
| `schema_get_procedure_definition` | `connectionId, database?, procedure` | `string` |
| `schema_get_functions` | `connectionId, database?` | `TableInfo[]` |
| `schema_get_function_definition` | `connectionId, database?, function` | `string` |
| `schema_get_users` | `connectionId, database?` | `DbUserInfo[]` |
| `schema_get_current_user` | `connectionId, database?` | `CurrentUserInfo` |

`tableParts` 是逐段解码后的标识符数组，段内的点号和引号必须保留，不可再次按点号拆分。MySQL 支持 `table`、`database.table`；PostgreSQL 支持 `table`、`schema.table` 和同库三段名；SQL Server 支持至多三段；SQLite 支持 `table`、`schema.table`。未限定 schema 时由数据库实际解析。返回的 `database` 为目标表所在库，可能不同于查询的默认库；SQLite 的 `database` 保留文件上下文、`schema` 标识 main/temp/附加库。

前端手工执行仍采用当前全局选择；执行开始后固定 `QueryExecution`。可确定来源的单表查询先解析身份，再用逐段引用的完整表名查询；网格保存使用 `EditContext`，取消使用运行记录，刷新使用原执行上下文及完整表名。迟到的旧结果不得覆盖新任务；无法确认单表身份的查询保留只读结果。批量脚本尚不支持后端取消，不填充旧查询的取消 ID。

SQLite 不支持的过程/函数等能力通常返回空列表或明确错误，调用方不应假设四种驱动的对象能力完全相同。

### 4.7 MCP 设置（3 个）

## 5. ConnectionPoolManager 行为

- 活动连接以 `connectionId -> Arc<dyn DatabaseDriver>` 保存在内存。
- 同 ID 重新连接时会先断开旧连接。
- 找不到活动连接时，会尝试读取已保存配置并自动重连。
- 未保存配置、未保存密码或密钥损坏时，自动重连可能失败。
- 删除已保存连接时会同时尝试断开活动连接。
- 更新已保存连接后会断开原活动连接，前端需要重新连接。

连接密码落盘格式为 `enc:v1:<nonce>:<cipher>`，密钥在同一配置目录的 `key.bin`。密码和密钥不得通过新增 IPC 暴露给前端。

## 6. DatabaseDriver 对接

驱动 trait 覆盖连接、查询、Schema、对象定义、用户、事务批处理、CSV、转储和标识符转义。新增数据库驱动需要完成：

1. 在 `src-tauri/src/database/` 新增驱动模块并完整实现 `DatabaseDriver`。
2. 在 `database/mod.rs` 导出模块。
3. 在 `test_connection()` 和 `create_and_connect_driver()` 注册驱动别名。
4. 扩展 `ConnectionConfig.driverType` 和连接对话框默认端口/字段。
5. 在 `src/lib/ddl.ts` 实现建库、建表和 ALTER 方言。
6. 扩展对象树的系统库、Schema 和能力判断。
7. 补充 `zh-CN.ts` 与 `en-US.ts`。
8. 建立真实数据库集成测试，覆盖查询、写入、取消、Schema、导入导出和特殊类型。

### 6.1 方言注意事项

- 所有数据库、Schema、表和列标识符必须调用驱动的 `escape_identifier` 或等价安全方法。
- 值优先使用参数绑定；无法参数化的 DDL 必须严格区分标识符和值。
- PostgreSQL 的 database 和 schema 不可混同。
- SQL Server 大计数使用 `COUNT_BIG` 或先转 `BIGINT`。
- SQLite 的 ALTER 能力受限，复杂结构调整可能需要重建表。
- MySQL/MariaDB 需要考虑字符集、GBK/GB18030 和元数据锁。

## 7. 新增或修改 IPC 的标准步骤

1. 明确是否可以复用已有命令或模型。
2. 修改或新增 Rust model，确认 serde 字段名。
3. 在 `commands/` 实现命令。
4. 在 `src-tauri/src/lib.rs` 注册命令。
5. 更新 `src/types/database.ts`。
6. 在 `src/services/tauriService.ts` 增加统一封装。
7. 由组件或 store 调用 service。
8. 同步中英文文案。
9. 增加 Rust、前端或集成测试。
10. 执行 `npm run build` 和 `cargo test --manifest-path src-tauri/Cargo.toml`。
11. 更新本文档的命令数量、参数和模型说明。

## 8. 对接安全红线

- 不新增返回明文密码、加密密码或密钥的命令。
- 不在日志中记录密码、Token、完整连接串或包含敏感值的完整 SQL。
- 不直接拼接未经转义的标识符。
- 不把 MCP 的词法只读检查当成数据库权限控制。
- 文件权限变化时同步审查 `src-tauri/capabilities/main.json`。
- 修改错误结构时必须考虑旧前端兼容，不要直接改变所有 `Result<T, String>` 的语义。
