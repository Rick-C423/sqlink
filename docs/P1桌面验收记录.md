## 验收范围与保留限制

本轮实际桌面覆盖正向保存、跨连接来源、NULL/空串、二进制、新增默认值、已确认失败后的草稿修正重试、PG 查询取消和普通结果只读。提交未知、回执丢失、清理中断、对象重建、整批冲突和连接复用的异常组合由真实数据库/故障注入及真实 React 组件自动化覆盖，未声称每一项都在桌面人工制造过。完整矩阵见 [P1实库验收记录](P1实库验收记录.md)。

以下既有范围没有因此扩大：

- PG 桌面表目录当前主要列出 public schema。本轮专用 PG 表从独立 schema 移至 public 后进行桌面验收；完整 schema 身份仍在后端网络回归及前端组件回归中核对，未把本次桌面结果扩大为全部 schema 浏览能力。
- 本次桌面截图记录了修复前的普通 SQL 大整数舍入：SQLite SELECT 的 `9007199254740993` 显示为 `9007199254740992`。随后已修复结果传输边界，并完成真实 SQLite、前端显示/复制及 SQL 转储回导自动化，见[普通查询大整数修复记录](普通查询大整数修复记录.md)。截图保留作历史证据；没有重新执行修复后的桌面验收。普通 SQL 始终只读，未参与行定位或本轮保存。
- 当前受控新增对没有可证明默认值的非空主键要求显式输入；本轮未扩展 SQLite 隐式 rowid 默认值推断。提交前拒绝不会执行 DML，补齐字段后可以重试。
- 取消结果的外层旧提示仍使用“执行失败”样式，但详细结果明确为“查询已取消”；统一任务展示仍有体验优化空间。

验收结束已关闭本轮独立窗口。专用钥匙串条目已按规范路径与账户逐项核对删除，并以 Windows `NoEntry/1168` 确认；临时数据库已优雅停止。本轮 5 个实验目录、专用验收 EXE、临时 Rust 编译缓存、专用配置和 WebView 缓存已完成路径/重解析点/进程归属核对后清理，共释放约 7.2 GB。保留源码、回归测试和脱敏证据。最终再次确认正式 EXE 哈希未变、用户原窗口仍在。
