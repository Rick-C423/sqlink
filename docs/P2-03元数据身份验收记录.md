# P2 03：元数据身份全链路

日期：2026-10-20。基线为 `53abb8f` 加既有未提交工作区。本轮保留此前 P0/P1/P2 改动和用户独立文档，没有提交、推送、发布或替换现用 EXE；网格编辑的凭据、数据库、类型、对象和会话门禁保持不变。

## 实现范围

表和视图从列表开始携带 connectionId、database、schema、table。连接树、工作区与草稿使用逐段 JSON 键，不反解显示名或 `::` 拼接字符串。数据页、结构页、视图定义、CSV 与 SQL 导出的来源均继续传递 schema；全选导出也固定当时选中的完整表清单，不隐式扩大到后来出现的表。显式空清单报错，不退回整库导出。

四驱动的列、索引、外键围绕 `ResolvedTable` 读取。旧 table 参数视为一个真实目录名称，名称内的点号不会被重新拆开；未指定库时读取当前实际库。PG 和 SQL Server 的表/视图目录展示实际用户 schema。SQLite 区分连接对应的数据库文件身份与 main/temp/ATTACH schema。

| 元数据 | 处理方式 |
| --- | --- |
| 索引主键、唯一性 | 读取真实目录标志，不从名称猜测 |
| 键顺序和降序 | 保留有序 keyParts；included 列单独返回 |
| 表达式、部分索引 | 保留表达式、谓词或原始定义；目录不能解码的表达式位保持未知，不伪装成列 |
| 复合外键 | 按约束列序位配对，不对两个列集合做笛卡尔联结 |
| 引用目标 | 保留 refDatabase、refSchema、refTable 和有序 refColumns |
| 复杂列列表 | 支持引用内逗号及转义引用，畸形输入明确报错；主键数组比较不再用逗号拼接 |

`schema_get_table_metadata` 一次返回后端解析的 target、indexes、foreignKeys、connectionGeneration 和 revision。结构草稿固定这份来源；`schema_execute_ddl` 提交前重新读取并比较修订，取得执行租约时再次核对连接代次。重连、旧修订或目录变化会拒绝提交并保留草稿。成功或失败的 DDL 都使旧结果上下文失效，因为数据库可能已经隐式或部分提交。

连接树右键的删除、清空、重命名以重新解析的 canonical 目标生成 SQL，保留原有确认交互。建表、结构、视图定义、概览和树加载均检查来源、请求序号或本地连接 epoch，迟到响应不写入后来连接的界面。刷新移除后代时同步释放旧 loading 标记，避免同 ID 重建后无法再加载。

前端结构缓存最多 128 项、8 MiB、TTL 30 秒，按连接、本地 epoch、后端 generation、database/schema/table 与类别区分。显式刷新、连接生命周期/切换、SQL/批执行/DDL/导入（含失败或部分生效）使对应缓存失效，迟到请求不能重新入缓存。库列表重新读取实际权限状态，不再使用跨生命周期的持久缓存。

## 导入与转储衔接

CSV 和 SQL 转储接受完整对象清单，在既有冻结任务、逐行原值编码、预算和原子文件替换上运行。MySQL 的读取带源库，恢复目标仍沿用所选导入库；PG 的非默认 schema 目标贯穿定义、INSERT 和回放。SQLite main 转储的 DROP/CREATE/INSERT 都限定 main，仅改写已识别的 CREATE 目标段，不全局替换原定义；temp/ATTACH SQL 转储仍明确拒绝，CSV 可读取已附加对象。

导入 skip 在同一已持有租约中参数化检查实际 CREATE 目标，保留各方言默认 schema、大小写规则、USE/search_path 与脚本内目录变化，避免另一个库/schema 的同名表使 CREATE 被误跳过。只跳过 CREATE，数据语句继续执行。既有导入 16 MiB 行/语句预算、整文件单租约、部分提交提示和失败清理保持有效。

## 明确边界

- revision 覆盖展示的列、索引、外键和连接代次，不等于物理对象世代。CHECK、触发器和同形重建未纳入该修订；提交前重读不是跨会话原子 DDL 锁，也不承诺多条 DDL 全成全败。可信网格写入继续依赖 P1 的独立对象核验与同事务门禁。
- 单对象序列化元数据超过 16 MiB 时拒绝发布，前端缓存另有 8 MiB 上限；驱动目录可能先收集行，未承诺元数据协议缓冲或进程 RSS 硬上限。本轮未测峰值 RSS。
- SQL 转储仍不是完整数据库备份，未新增全部触发器、权限、依赖顺序、扩展类型和索引恢复。例程/触发器的全 schema 浏览不属于本轮表/视图元数据范围。
- 导出任务启动后固定后端连接代次；不能把启动前表目录选择声称为可跨同 ID 重连继续有效的代次快照。导入完整 ImportPlan、恢复检查点、DatasetController 及首屏/统计解耦仍待后续。
