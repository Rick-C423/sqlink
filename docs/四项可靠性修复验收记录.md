## 1. 过期草稿与提交结果证据

后端在结果上下文或行句柄校验阶段拒绝请求时，仅在确认结果 ID 由本管理器发行，并在回执注册表同一把锁内确认没有同 ID 执行记录、没有占用该快照的未决或已提交请求后，登记“明确未执行”记录，再返回绑定变更 ID、结果 ID 和版本的 `commitEvidence`。登记失败、旧进程引用、发行历史已淘汰、预算不足和锁故障均不签发证据。

未执行记录同时阻止迟到的同 ID 请求开始执行；不同内容不能复用该 ID。详情 TTL 到期后仍保留摘要、身份、证据及预算占用，核查可返回 `COMMIT_NOT_EXECUTED`。普通回执过期或缺失不能转为未执行证明。发行历史和回执 ID 数量均有界；无法证明时继续按未知处理。

前端只接受严格匹配原请求的证据。明确未执行后保留输入，可放弃草稿或重新读取固定来源。恢复需核对新上下文、相同连接代次、完整表来源、物理对象与结构摘要、当前操作和类型权限，以及每条受影响原始行的完整无损值。缺页、重复、原值变化、表重建、结构变化、缺少摘要或无法无损读取时拒绝恢复，并保留原输入供人工复制核对。

重新读取和确认恢复均不写库。确认只迁移本地输入到新上下文、新列引用及新行句柄；下一次用户显式保存才生成新变更 ID。没有回执、响应丢失或普通错误仍保持未知及原有导航限制，绝不据此自动重放写入。

恢复预览与原草稿分别固定上下文；页面通过 DatasetController 持有当前结果。取消、失败、卸载、重挂及迟到结果均检查页面与草稿引用，防止提前释放或遗留孤立预览。确认时再次核对预览有效期。

回归包括 SQLite 拒绝后读库无变化、同 ID 防重放、回执查询、跨管理器及发行历史淘汰、锁与预算失败、并发预留仲裁、前端未知状态保护、恢复时行重排、新身份提交、失败与取消、预览卸载重挂及共享页面引用。

## 2. 普通 SQL 批执行的部分生效状态

通用批处理在每条用户 SQL 可能发出前原子登记发送边界。只要发出过 SQL，失败或取消后即使当前事务回滚和会话清理成功，也保守记录整批 `commitState=unknown`，保留原始 SQL 错误并提示可能部分生效、需人工核对及禁止盲目重发。尚未发送用户 SQL 的取消保持 `notStarted`。外层 COMMIT 已确认后，清理失败不能倒退为未提交。

该路径不改变受控网格提交及文件导入协议，也不尝试通过静态 SQL 分类证明任意脚本可完全回滚。

SQLite 回归实际验证：显式 COMMIT 后语句失败、COMMIT 后取消、COMMIT 后新开事务再失败，已提交行仍存在；当前未提交部分会被回滚。另覆盖发送前取消、外层 COMMIT 失败原因、提交确认后清理失败，以及前端原错误和部分生效提示传播且只调用一次提交。

## 3. 首次钥匙串故障后的初始化恢复

仅当没有持久化密钥状态、没有旧密钥文件且所有落盘密码均为空时，允许空钥匙串初始化。无密码连接记录不再被视为旧密钥依赖。已有密文、迁移状态、旧密钥和任何读取故障继续沿用保护；不允许以读取失败替代明确的条目不存在，不改旧明文迁移和平台回退边界。

使用 mock 钥匙串和临时目录，覆盖首次故障期间保存无密码连接、恢复后初始化、保存密码及重启解密，以及读取错误零次写钥匙串、各类密文和状态指针禁止换钥。未使用用户实际凭据配置。

## 4. MCP query_scalar 大整数传输

标量响应复用普通结果的 `integer_display_json`：超出 JavaScript 安全整数范围的整数以精确十进制字符串传输；安全整数、浮点数、文本、布尔和 NULL 语义保留。不递归改写嵌套 JSON，保持一行一列、只读校验和响应预算。

真实内存 SQLite 覆盖正负整数边界，经过实际 rmcp 返回类型转换、外层 JSON 序列化和文本 JSON 解析后核对结果；另覆盖 `u64::MAX`、非整数与行列数量限制。当前 rmcp 1.7 返回 `content[0].text`，不生成 `structuredContent`；测试明确断言该协议形态。
